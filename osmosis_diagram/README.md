# Diagrama de tonicidad / ósmosis celular

Genera una figura educativa en español con tres condiciones:

- **Isotónica** — sin flujo neto de agua
- **Hipotónica** — entrada neta de agua (la célula se hincha)
- **Hipertónica** — salida neta de agua (la célula se encoge)

## Convención de flechas

- Flechas **sólidas**: movimiento de agua **hacia el exterior** de la célula
- Flechas **discontinuas**: movimiento de agua **hacia el interior** de la célula

## Uso

```bash
python3 osmosis_diagram/generate_tonicity_diagram.py
```

Salida: `osmosis_diagram/tonicity_osmosis_diagram.png`
